# Steps a Software Engineer Follows to Use SDPTool

## Brief Overview
A software engineer uses SDPTool through a tabbed GUI interface to create datasets from GitHub repositories, preprocess data, configure ML models, train them, and analyze predictions for software defect prediction tasks.

## Workflow Steps

1. **Configuration Tab** - Set up GitHub access token, repository details, database path, and fetch issues data from GitHub
2. **Database Preprocessing & Validation Tab** - Clean and validate the fetched data through automated pipeline steps
3. **Feature and Sample Selection Tab** - Configure dataset parameters (test/train split, balancing, feature selection methods)
4. **AI Techniques Tab** - Select ML algorithms (MultinomialNB, LogisticRegression, RandomForest, CNN, MLP), enable cross-validation, error analysis, and run training
5. **Visualizations Tab** - View generated charts (confusion matrices, feature importance plots)
6. **Predictions Tab** - Browse historical training runs and view HTML reports with comprehensive model performance metrics

## Key Features
- Multi-label and multi-class classification support
- Automated data preprocessing pipeline
- Multiple ML algorithms with hyperparameter tuning
- Statistical significance testing and error analysis
- Comprehensive HTML reports with performance comparisons
- Run history management
